Lenguajes principalmente utilizados

HTML es el acrónimo de HyperText Markup Language, que en español se traduce como Lenguaje de Marcado de Hipertexto. HTML es el esqueleto o la estructura de una página web, es el código que le dice al navegador (como Chrome, Firefox o Safari) qué elementos debe mostrar y en qué orden deben aparecer; sin este esqueleto, la página sería un caos sin organización.

En resumen HTML hace la organización de la pagina correspondiente, para obtener esta organizacion se necetitan herramientas llamadas "etiquetas" cada una de ellas manda la instruccion de como va organizada deacuerdo a lo que es (titulos, imagenes, parrafos,etc). Acontinuacion se mostraran algunas de ellas:

Etiquetas basicas:

  1. html: Indica el inicio y el final del documento"
  2. head:Contiene información de la página, como su configuración.
  3. titleDefine el título que aparece en la pestaña del navegador.
  4. body:Contiene todo el contenido visible de la página.
  5. h1:Crea un titulo principal.
  6. h2-h6:Crean titulos de diferentes niveles.
  7. p:Crean encabezados de diferentes niveles.
  8. br:Inserta un salto de línea.
  9. strong:Indica que un texto es importante, normalmente en negrita.
  10. a:Crea un enlace a otra página o sitio web (hipervinculo).

Etiquetas para multimedia:

  1. img:Inserta una imagen.
  2. audio:Permite insertar audio.
  3. video:Permite insertar videos.

Etiquetas para listas:

  1. ul:Crea una lista con desordenada.
  2. ol:Crea una lista ordenada.
  3. li:Define un elemento de una lista.
  4. dl:Crea una lista de definiciones.

Etiquetas para tablas:

  1. table:Crea una tabla.
  2. tr:Crea una fila.
  3. th:Crea una celda de encabezado.
  4. td:Crea una celda con información.

CSS significa Cascading Style Sheets (hojas de estilo en cascada). Se utiliza para darle diseño a una página web, modificando sus colores, tamaños, márgenes, imágenes, posiciones y tipos de letra.

A diferencia de HTML, CSS utiliza selectores, propiedades y valores, no etiquetas como tal, con CSS, los desarrolladores y diseñadores pueden controlar cómo se muestran los elementos en la web en la que estén trabajando, desde el color y la fuente hasta la disposición de los elementos en la pantalla, pasando por animaciones y efectos visuales. Esta separación entre el contenido y la forma en que se presenta a los usuarios permite mejorar la accesibilidad, brinda mayor flexibilidad y control y facilita la actualización y el mantenimiento de las páginas web.

Selectores principales:

  1. *:Selecciona todos los elementos.
  2. .clas:Selecciona elementos que tienen una clase.
  3. #id:Selecciona un elemento por su identificador.

Propiedades para texto:

  1. color:Cambia el color del texto.
  2. font-size:Cambia el tamaño de la letra.
  3. font-family:Cambia el tipo de letra.
  4. font-style:Aplica estilos de letra.
  5. text-align: Alinea el texto a la izquierda, derecha o centro.

Propiedades para el fondo:

  1. background-color:Cambia el color de fondo.
  2. background-image:Coloca una imagen de fondo.
  3. background-size:Ajusta el tamaño de la imagen de fondo.
  4. background-repeat: Controla que la imagen de fondo no se repita.
  5. opacity:Cambia la transparencia de un elemento.

Propiedades para margenes, bordes y tamaños:

  1. margin:Agrega espacio por fuera de un elemento.
  2. paddingAgrega espacio entre el contenido y el borde.
  3. border:Agrega un borde.
  4. border-radius:Redondea las esquinas.
  5. whidth:Define el ancho.
  6. height:Define la altura.
  7. box-shadow:Agrega una sombra.

Propiedades para imagenes:

  1. whidth:Define el ancho de la imagen.
  2. height:Define la altura.
  3. max-whidth:Evita que la imagen supere un ancho determinado.
  4. object-fitAjusta cómo se adapta la imagen a su espacio.
  5. object-position:Cambia la posición de la imagen dentro de su espacio.
  6. margin:auto:Puede centrar horizontalmente una imagen de bloque con ancho definido.
